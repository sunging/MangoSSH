MangoSSH is a free and open-source SSH and Mosh client for Android phones and tablets. Profiles and keys stay in an encrypted vault, and encrypted backups can live on your own WebDAV server.

Sessions:
* SSH and native Mosh terminals; Mosh keeps an authenticated SSH companion for files, port forwards, and server resource reports
* Jump hosts, SSH agent forwarding, and optional tmux workspaces that reattach on reconnect
* Snippets that run automatically when a shell opens
* Live connection health and sessions that stay up in the background

Authentication and security:
* Password, private-key, and keyboard-interactive authentication with one-time password prompts
* Explicit host-key confirmation and a clear warning when a saved key changes
* Generate, import, and export RSA, ECDSA, and Ed25519 keys
* Encrypted local vault for profiles, keys, and host fingerprints
* App lock with PIN or biometrics and a configurable auto-lock delay

Files and forwarding:
* SFTP browser with file and folder upload and download
* Pause, resume, and retry transfers, and continue them after reconnecting to the same verified host
* Edit small text files in place with a diff preview and encrypted drafts
* Local, remote, and SOCKS5 port forwarding, with or without an open terminal

Networking:
* Per-profile route: direct, the system Tailscale VPN, or an embedded, outbound-only Tailscale node (tsnet)

Terminal:
* Cascadia Mono PL, JetBrains Mono NL, and Fira Code fonts
* Mango Dark, Dracula, Nord, and Solarized themes, or custom colors
* Configurable shortcut bar, scrollback, pinch-to-zoom, and immersive mode

Backup and more:
* Encrypted file and WebDAV backups with a preview before merging, recovery points, and remote history
* Import hosts from an OpenSSH config file
* English and Simplified Chinese; two-pane layout on tablets

Mosh is rebuilt from the included GPL-licensed source for arm64-v8a, armeabi-v7a, x86, and x86_64. Embedded Tailscale is opt-in, does not request Android VPN access, and requires the user to authorize their own Tailnet account.

MangoSSH does not include advertisements or analytics. Credentials, private keys, host fingerprints, OTP answers, and session keys are never included in diagnostics.
