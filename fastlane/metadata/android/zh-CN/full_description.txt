MangoSSH 是面向 Android 手机和平板电脑的自由开源 SSH 与 Mosh 客户端。连接配置和密钥保存在加密保险库中，加密备份可以存放在你自己的 WebDAV 服务器上。

会话：
* SSH 终端和原生 Mosh 终端；Mosh 会话保留一条已认证的 SSH 伴随连接，用于文件、端口转发和服务器资源信息
* 跳板主机、SSH agent 转发，以及重连后自动重新接入的 tmux 工作区（可选）
* Shell 打开后自动执行的代码片段
* 实时连接健康状态，会话可在后台保持运行

认证与安全：
* 密码、私钥及键盘交互认证，支持一次性密码提示
* 明确的主机密钥确认，已保存的密钥变化时给出警告
* 生成、导入和导出 RSA、ECDSA、Ed25519 密钥
* 连接配置、密钥和主机指纹保存在本地加密保险库中
* 应用锁支持 PIN 和生物识别，自动锁定延迟可调

文件与转发：
* SFTP 文件浏览，支持文件和文件夹的上传与下载
* 传输可暂停、继续和重试，重新连接到同一台已验证的主机后可继续传输
* 直接编辑小型文本文件，保存前预览差异，草稿加密保存
* 本地、远程和 SOCKS5 端口转发，无需保持终端打开

网络：
* 每个连接配置可选路由：直连、系统 Tailscale VPN，或仅出站的内嵌 Tailscale 节点（tsnet）

终端：
* Cascadia Mono PL、JetBrains Mono NL 和 Fira Code 字体
* Mango Dark、Dracula、Nord、Solarized 主题，也可自定义颜色
* 快捷键栏、回滚行数、双指缩放和沉浸模式均可配置

备份及其他：
* 加密的文件备份与 WebDAV 备份：合并前可预览，支持恢复点和远程历史版本
* 从 OpenSSH config 文件导入主机
* 支持英文和简体中文；平板上使用双栏布局

Mosh 针对 arm64-v8a、armeabi-v7a、x86 和 x86_64 从随附的 GPL 源码重新构建。内嵌 Tailscale 功能须由用户主动启用，不申请 Android VPN 权限，并需要用户授权自己的 Tailnet 账户，可使用 Tailscale 官方服务或 Headscale 等自建控制服务器。

MangoSSH 不含广告或分析统计。凭据、私钥、主机指纹、一次性密码答案及会话密钥不会出现在诊断信息中。
